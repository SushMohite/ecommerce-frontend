🛒 ShopEase – E-Commerce Frontend Project
📌 Overview

ShopEase is a modern frontend e-commerce web application built using HTML, CSS, and JavaScript.
It allows users to browse products, view details, add items to cart, and manage authentication using Firebase.

The project focuses on performance, usability, and real-world e-commerce functionality.
